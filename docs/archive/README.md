# Documentation Archive

This directory preserves historical BEKAL planning, scope-freeze, release-candidate, and milestone documents.

These files are retained because they explain how the project reached its current design. They are **not** the primary instructions for the current `master` branch.

## Archive structure

```text
docs/archive/
├── v0.1/   original V0.1 charter, requirements, architecture, ADR, privacy, roadmap, document index, README draft, release-candidate and public-release preparation
└── v0.2/   desktop-shell and Windows-packaging milestone records
```

## Important

Archived documents may contain wording that was true at the time but is no longer current, including references to:

- the repository still being private;
- future public release work;
- a Windows installer still being planned;
- feature branches still awaiting merge/cleanup;
- earlier implementation phases as the current phase.

Do not copy those statements into current guidance without checking the current codebase and current documentation.
