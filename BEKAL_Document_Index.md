# Project BEKAL — Document Index

This document set defines the agreed V0.1 scope before implementation.

1. **BEKAL_Project_Charter_V0.1.md** — purpose, goals, principles, and scope boundary.
2. **BEKAL_Requirements_V0.1.md** — functional/non-functional requirements and acceptance test.
3. **BEKAL_System_Architecture_V0.1.md** — component architecture, data flow, and core entities.
4. **BEKAL_ADR_V0.1.md** — accepted architecture decisions.
5. **BEKAL_Data_Privacy_Security_V0.1.md** — Git/privacy rules and public-release safety gate.
6. **BEKAL_Development_Roadmap_V0.1.md** — phased implementation plan and backlog boundary.
7. **README_BEKAL_DRAFT.md** — future repository landing-page draft.

## V0.1 Scope Lock

The V0.1 finish line is the acceptance test defined in `BEKAL_Requirements_V0.1.md`.

New ideas may be recorded in the backlog, but should not enter V0.1 unless they are required to satisfy an existing acceptance criterion or fix a blocker.
